# Condo Documents

A polished public condominium document portal built as a client-side React SPA.

## Development

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Routes

- `/` — public document center
- `/admin` — administration placeholder

The included `public/_redirects` file provides SPA history fallback when deployed to Netlify.
